
# NetBox container

This role implements creation and configuration of a Docker container, running NetBox.
The container runs in a dedicated container network with a configurable IPv4 address.

NetBox requires one Postgres and two Redis databases to run.
with which it is deployed in a dedicated network with configurable subnet mask.
